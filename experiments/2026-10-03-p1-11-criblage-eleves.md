# Fiche préenregistrée : criblage des points de départ LLM, pli 0 (P1-11, ADR-009)

- **question** : parmi Qwen3.5-4B, Qwen3.5-9B et Gemma-4-E4B (ADR-009), lequel obtient la macro-F1 la plus haute sur le pli 0 avec la LoRA du socle, à chacun des deux taux 1e-5 et 1e-4 ? La règle de choix de l'élève (P1-12) est celle d'ADR-009, appliquée après coup sans être rouverte.
- **référence** : TF-IDF v1 sur le pli 0 (`p1-06-tfidf-chapter`, macro-F1 du pli 0 : 0,6971), bornes `p1-03-bounds`, encodeur de P1-07 si disponible.
- **variante** : le modèle de départ (un seul changement entre candidats ; mêmes réglages).
- **jeux et découpage** : développement seulement ; entraînement sur les plis 1 à 4, évaluation sur le pli 0 ; test scellé jamais lu ; 17 classes évaluées, `AUTRE` exclue de la moyenne.
- **configuration fixée (identique pour les trois)** : `AutoModelForSequenceClassification` (voie A, Qwen) ou tête sur le dernier token (voie B, Gemma, `src/llmft/last_token.py`), LoRA sur toutes les couches linéaires, **rang 16, alpha 32**, dropout 0,05 (choix de l'assistant de nuit, plus petit que le départ r = 64 de la recette pour tenir la mémoire et le temps ; rang et alpha se balayent plus tard, P1-14), bf16, gradient checkpointing, AdamW sans décroissance de poids, échauffement 20 pas puis cosinus, **2 époques**, lot effectif 32 (micro-lot 1), graine `s_0 = 1000`, **4 096 tokens** de texte (2 048 de tête, 2 048 de fin, marqueur `[...]`). Taux ∈ {1e-5, 1e-4} (bornes de la grille de P1-13), six runs.
- **métrique principale** : macro-F1 (17 chapitres) sur le pli 0. **Secondaires** : exactitude, log loss, log loss équilibrée par chapitre, ECE, durée, pic de mémoire réservé (limite de 28 Gio).
- **critère de décision** : ADR-009 (plus haute macro-F1 sous contrainte de mémoire ; règle d'égalité de l'ADR). Aucun verdict de gain : un pli, une graine, exploratoire. Un run dont la perte devient non finie est enregistré `failed` (divergence, taux exclu du choix, non relancé) ; une panne mémoire est relancée une fois à lot effectif égal.
- **budget** : projection par le débit moyen mesuré (`debit-qwen3-5-4b-lora-4096`, `debit-qwen3-5-9b-lora-4096`, `debit-gemma-4-e4b-lora-4096`, 6 pas de 8 exemples au hasard, processeur libre) : 0,54 s, 0,87 s et 0,65 s par exemple, soit 52 min, 83 min et 63 min pour deux époques sur 2 869 patients, **environ 6,6 h pour les six runs** plus 3 à 5 min d'évaluation et de chargement par run ; hypothèse, non annoncée comme durée. **Arrêt anticipé** (PROTOCOLE.md section 5) : run interrompu et enregistré `aborted` si, après 10 % des pas, la durée projetée dépasse 1,5 fois l'estimation (limites : 4 630 s, 7 460 s, 5 630 s). Alerte à 80 % de B (72 h). Plafond mémoire 30 Gio, délai d'inaction 20 minutes.
- **prédiction** : macro-F1 du pli 0 entre 0,55 et 0,85 pour le meilleur candidat (probabilité 0,7) ; le meilleur LLM dépasse le TF-IDF sur ce pli (0,6971) avec probabilité 0,6 ; taux 1e-4 meilleur que 1e-5 pour au moins deux candidats sur trois (probabilité 0,7) ; le Qwen3.5-9B est le meilleur des trois (probabilité 0,4).
