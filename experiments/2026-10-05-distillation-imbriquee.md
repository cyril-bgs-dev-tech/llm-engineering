# Fiche préenregistrée : distillation à professeur imbriqué, contrôle de la fuite de second ordre (RM-56, EXPLORE, cinq plis)

Écrite avant les runs, après le verdict de `2026-10-04-distillation-vers-encodeur` (bras ensemble : élève moins non distillé +3,47 [+2,25 ; +5,08], élève moins professeur +2,31 [+0,46 ; +4,48]).

- **question** : le gain de l'élève encodeur distillé de l'ensemble encodeur + TF-IDF survit-il quand le professeur n'a jamais vu le pli d'évaluation de l'élève ? (Dans la fiche d'origine, le professeur du pli `j` avait été entraîné sur les plis autres que `j`, donc **y compris le pli `k` évalué** : fuite de second ordre possible.)
- **variante** : pour chaque pli évalué `k` et chaque pli d'entraînement de l'élève `j ≠ k`, un professeur **imbriqué** entraîné sur les trois plis ∉ {j, k} et prédisant `j` : encodeur CamemBERT-bio, recette gelée (10 époques, 1e-4, 508 tokens), **deux graines** (1000 et 1001), moyennées, mélangées 50/50 avec un TF-IDF caractères (3 à 5) à poids équilibrés (C = 100, non réglé), soit 20 couples, 40 encodeurs et 20 TF-IDF ; puis les élèves du pli `k` entraînés sur les quatre autres plis avec ces professeurs imbriqués, **mêmes paramètres que le bras ensemble de la fiche d'origine** (alpha 0,5, T = 2, graines 1000 à 1002, `scripts/p3_distill.py`) : 15 runs, slugs `distill-nested-pliK-sS`. Scripts : `p1_encoder_nested.py`, `nested_tfidf.py`, `build_nested_teachers.py`.
- **références** : encodeur non distillé (mêmes graines), élève non imbriqué (fiche d'origine, bras ensemble), ensemble professeur non imbriqué.
- **jeux et découpage** : développement, plis 0 à 4 ; test scellé jamais lu. Le professeur imbriqué est entraîné sur trois plis seulement (moins de données que l'original) : il est plus faible que le professeur d'origine, ce qui biaise **contre** le gain.
- **métrique principale** : macro-F1 regroupée de la moyenne des trois graines ; différences par bootstrap d'auteurs (`llmft.cluster_bootstrap`, IC 95 %) : (i) élève imbriqué moins non distillé ; (ii) élève imbriqué moins élève non imbriqué.
- **critère de décision** : « gain préservé » si la borne basse de (i) est > 0 et la différence ≥ δ = 2,0 ; « gain partiel » si la borne basse de (i) est > 0 mais la différence < δ ; « gain non préservé » si la borne basse de (i) est ≤ 0 ; « fuite significative » si la borne basse de (ii) est > 0 pour (non imbriqué moins imbriqué), c'est-à-dire si l'écart de (ii) est négatif avec borne haute < 0.
- **budget** : environ 3,5 h de GPU (40 encodeurs de 3 minutes, 15 élèves de 4 minutes) et 25 minutes de processeur ; après les reprises de service (TERMINE29) ; codes 134 et 139 seuls relancés (N25).
- **prédiction** : (i) gain préservé (probabilité 0,5) ou partiel (0,3) ; (ii) élève imbriqué à moins de 1,5 point de l'élève non imbriqué (0,6) ; fuite significative (0,2).
