# Fiche préenregistrée : distillation vers l'encodeur, professeur strictement hors pli (RM-32, EXPLORE, cinq plis)

Écrite avant les runs. Dépend de RM-28 (probabilités hors pli du LoRA mûr sur les cinq plis). Thèse du projet : retrouver la qualité du LoRA à coût d'encodeur.

- **question** : (a) un encodeur CamemBERT-bio affiné sur l'étiquette **et** sur les probabilités hors pli du LoRA mûr dépasse-t-il de plus de δ = 2,0 points le même encodeur sans professeur ? (b) s'approche-t-il du LoRA ? (c) bras exploratoire : même question avec pour professeur l'ensemble encodeur + TF-IDF (compression d'ensemble vers un seul modèle).
- **références** (mêmes patients, plis 0 à 4) : encodeur non distillé, graines 1000 à 1002 (runs `camembert-recette-lr1e-4-ep10`, `camembert-graine-ep10-s1`, `camembert-graine-ep10-s2` pour le pli 0 ; `camembert-pliK-ep10-s0` à `s2` pour les autres plis), moyennées en probabilités ; LoRA mûr (professeur) ; meilleur TF-IDF.
- **variante** : `scripts/p3_distill.py`, perte `alpha_kd * CE + (1 - alpha_kd) * T^2 * KL`, **alpha_kd = 0,5 et T = 2 fixés ici, non réglés** (P3-02 ; budget) ; reste identique à la recette de l'encodeur (10 époques, taux 1e-4, 508 tokens, lot effectif 32, micro-lot 16) ; professeur : bras (a) LoRA graine 1000 de chaque pli (`llm-mur2-qwen3-5-4b-ep10-lr1e-4` pour le pli 0, `llm-mur-pliK-qwen3-5-4b-ep10-lr1e-4` pour K = 1 à 4) ; bras (c) ensemble encodeur + TF-IDF (fichiers par pli). Trois graines (1000 à 1002) par pli et par bras : 30 runs.
- **jeux et découpage** : développement, plis 0 à 4 ; test scellé jamais lu. L'élève du pli k n'utilise que les professeurs des plis autres que k (contrôle strict `oof_teacher_map` ; l'empreinte des fichiers de professeur est consignée dans chaque run). **Réserve déclarée** : chaque professeur a vu le pli k de validation de l'élève (second ordre) ; l'évaluation de l'élève est donc légèrement optimiste, le test scellé en est exempt.
- **métrique principale** : macro-F1 sur 17 chapitres (AUTRE exclu), prédictions regroupées sur les cinq plis ; secondaires : par pli, exactitude, log loss, ECE, incertitude, coût d'inférence (identique à l'encodeur : 191 ms sur processeur).
- **critère de décision** : différence appariée sur prédictions regroupées (`power_rule.pooled_interval`, IC 95 %, moyenne des trois graines en probabilités de chaque côté) : (a) « gain confirmé » si la borne basse est > 0 et la différence ≥ δ ; « sans gain » si l'IC tient dans ±δ ; sinon « non résolu » ; (b) écart à la macro-F1 du LoRA rapporté tel quel ; (c) idem (a). Largeur seuil 4,0 de la règle v2.
- **budget** : 30 runs d'environ 5 minutes (2,5 h de GPU) ; GPU libre, aucun calcul concurrent ; essais multiples uniquement sur panne du tokenizer (codes 134 et 139), consignés (N25).
- **prédiction** : (a) l'encodeur distillé du LoRA dépasse l'encodeur non distillé de 1 à 4 points (probabilité 0,55), IC entièrement positif (0,5), gain ≥ 2,0 (0,35) ; (b) l'élève reste à plus de 2 points sous le LoRA moyen des cinq plis (0,6) ; (c) le bras ensemble n'apporte pas plus que le bras LoRA (0,6).
